Rokid AI Glasses RV101上で、現在接続しているWi-Fiアクセスポイント名（SSID）を確認し、接続先を切り替えるアプリです。

**現在のバージョン: 1.0.0**

[Androidスマートフォンで最新版APKをダウンロード](https://github.com/ksuzukigh/rokid-wifi-selector/releases/latest/download/Rokid-Wi-Fi-Selector.apk)

## Wi-Fi Selectorで選べる接続先

Wi-Fi Selectorで選べるのは、Hi Rokidアプリであらかじめメガネに設定したWi-Fiアクセスポイントです。

新しいアクセスポイントの登録やパスワードの入力は、Hi Rokidアプリの「グラス設定」→「デバイス」→「眼鏡 Wi-Fi ネットワーク」で行います。Wi-Fi Selectorを開くと、設定済みのアクセスポイントの中から、現在利用できる切替先が表示されます。

## できること

- Rokidが現在接続しているWi-Fiアクセスポイント名（SSID）を表示
- Hi Rokidアプリで設定したアクセスポイントの中から、現在利用できる切替先を表示
- テンプルの左右スワイプで候補を選び、1回タップして接続
- 15秒以内に接続できなかった場合は、切替を中止して、切替前のWi-Fiへ自動的に戻る

Wi-Fi Selectorでは、アクセスポイントの新規登録、パスワードの入力、登録内容の削除は行いません。

## 操作方法

1. Rokidのアプリ一覧から「Wi-Fi Selector」を開きます。
2. `接続中`に現在の接続先、`切替先`に切替先候補が表示されます。
3. 接続先候補が複数ある場合は、テンプルを左右にスワイプして選択します。
4. テンプルを1回タップすると、選択したアクセスポイントへ接続されます。
5. 接続後は接続先を表示して、アプリ一覧へ戻ります。

Hi Rokidアプリで設定したアクセスポイントのうち、近くで利用できる切替先がほかにない場合は、切替操作を行いません。

## 初回の位置情報許可

Androidは、Wi-Fiアクセスポイント名（SSID）と周辺のWi-Fiをアプリへ表示する際に位置情報の許可を要求します。初回起動時に「許可」を選んでください。

本アプリはインターネット接続の権限を持たず、現在地、Wi-Fiアクセスポイント名（SSID）、利用履歴を外部へ送信しません。

## 用意するもの

- Rokid AI Glasses RV101
- Hi Rokidを入れたAndroidスマートフォン
- Hi Rokidアプリでメガネに設定済みのWi-Fiアクセスポイント

Androidスマートフォンからのインストールを実機確認しています。iPhoneから同じ方法でインストールできるかは未確認です。

## Androidスマートフォンからインストール

### 1. APKをダウンロードする

1. Androidスマートフォンで[最新版APK](https://github.com/ksuzukigh/rokid-wifi-selector/releases/latest/download/Rokid-Wi-Fi-Selector.apk)をダウンロードします。
2. ファイル名が`Rokid-Wi-Fi-Selector.apk`であることを確認します。

### 2. Hi RokidからRokidへ入れる

1. スマートフォンでHi Rokidを開き、Rokidと接続します。
2. 「ホーム」→「ツールボックス」→「メガネのアプリ管理」の順に開きます。
3. 画面下の「新しいアプリをインストール」を押します。
4. 案内を確認し、「確認しました。ファイルを選択する」を押します。
5. 「最近」または「ダウンロード」から`Rokid-Wi-Fi-Selector.apk`を選びます。
6. 表示されたアプリ名と権限を確認し、「同意してインストール」を押します。

「メガネのアプリ管理」に「Wi-Fi Selector」が表示されればインストール完了です。Hi Rokidの画面名は、アプリのバージョンや表示言語によって異なる場合があります。

## 困ったとき

### 切替先が表示されない

- 切替先のアクセスポイントが近くで利用できるか確認します。
- そのWi-FiがRokidへ保存済みか、Hi Rokidの「グラス設定」→「デバイス」→「眼鏡 Wi-Fi ネットワーク」で確認します。
- Wi-Fi Selectorを閉じて、もう一度開きます。

### 位置情報を許可しなかった

Wi-Fi Selectorを開き直し、許可画面で「許可」を選びます。許可画面が再表示されない場合は、Rokidのアプリ設定からWi-Fi Selectorの位置情報を許可してください。

### Hi RokidでAPKを選べない

- スマートフォンのブラウザーでAPKのダウンロードが完了しているか確認します。
- ファイル名の末尾が`.apk`になっているか確認します。
- ファイル選択画面で「最近」または「ダウンロード」を開きます。

### 「メガネのアプリ管理」を開けない

Hi Rokidの案内に従い、スマートフォンのWi-Fiを一時的に有効にしてから、もう一度「メガネのアプリ管理」を開きます。インストール後は、スマートフォンを普段使っている通信状態へ戻せます。

## 安全性とプライバシー

- インターネット権限を持たず、外部通信を行いません。
- Wi-Fiのパスワードを読み取り、保存、送信しません。
- Hi Rokidアプリで設定したアクセスポイントの登録内容を追加・削除・変更しません。
- 接続先を選んだ時だけ、Androidの保存済み設定へ接続を要求します。
- 位置情報の許可はWi-Fiアクセスポイント名（SSID）を表示するためだけに使用します。
